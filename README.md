# Minecraft Lazy Accelerated Pig Cannon Calculator

A web-based Minecraft Pig Cannon ballistics calculator & tick-by-tick trajectory simulation tool.

Designed with the exact visual layout and responsive design of the **Lazy Chunk Boat Cannon Calculator**, featuring fast $O(1)$ analytical pig ballistics solving and boat stack push physics.

## Features

- **Boats per Stack**: Input your boat count per stack.
- **Collision Duration Outputs**: Calculates exact collision ticks for Stack 1 & Stack 2 alongside total travel time.
- **Tick-by-Tick Telemetry Inspector**: Shows full position $(X, Y, Z)$, velocity $(V_x, V_y, V_z)$, speed, and phase (`Colliding` / `Free Flight`) for every single tick.
- **Interactive Trajectory Visualizer**: Toggle between 2D Top Radar (X-Z) and Side Elevation Profile (X-Y).
- **1-Click Teleport Commands**: Copy `/tp @p` and `/tp @e[type=pig]` commands instantly.

## Usage

Simply open `index.html` in any modern web browser or visit the live GitHub Pages deployment.
